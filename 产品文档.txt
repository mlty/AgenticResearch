Agentic Research System 开发文档（MVP → 完整系统）
1. 项目目标
构建一个面向计算机科研（CVPR / NeurIPS 等顶会）的 Agentic Research System，用于自动化并加速科研流程，包括：
● Topic 选择
● 文献调研与 Idea 生成
● 算法实现与实验
● 实验分析与迭代
● 论文撰写（LaTeX）
目标不是完全自动发论文，而是：
提升 research efficiency（3–10x）

2. 系统总体架构
系统采用多 Agent + Task Graph + Shared Memory 架构：
User Goal → Planner Agent → Task Graph → Specialized Agents → Memory → Feedback Loop
模块划分：
1. Planner Agent（任务分解）
2. Topic Agent（选题）
3. Research Agent（文献 & idea）
4. Coding Agent（实现）
5. Experiment Agent（实验执行）
6. Evaluation Agent（结果分析）
7. Iteration Agent（优化迭代）
8. Writing Agent（论文生成）

3. 核心模块设计
3.1 Planner Agent
功能：
● 接收用户目标（如：发 CVPR）
● 拆解任务为 DAG（Task Graph）
输入：
● 用户目标
输出：
● Task Graph（JSON）
示例：
{
"tasks": [
"topic_selection",
"literature_review",
"idea_generation",
"implementation",
"experiment",
"analysis",
"paper_writing"
]
}

3.2 Topic Agent
功能：
● 分析 research trend
● 提取 research gap
● 输出候选方向
输入：
● 论文数据库（RAG）
输出：
{
"topic": "...",
"motivation": "...",
"novelty": "...",
"related_work": [...]
}

3.3 Research / Idea Agent
功能：
● 阅读论文（PDF parsing）
● 总结方法
● 提出创新点
关键能力：
● limitation mining
● idea generation（multi-step reasoning）
输出：
{
"idea": "...",
"method": "...",
"pseudo_code": "..."
}

3.4 Coding Agent
功能：
● 生成 PyTorch 代码
● 修改现有 repo
● 自动 debug
依赖：
● Git
● Python execution environment
● GPU
输出：
● 可运行代码
● config 文件

3.5 Experiment Agent（核心）
功能：
● 自动运行实验
● 管理参数
● 调参（grid / Bayesian）
输入：
● code
● config
输出：
{
"exp_id": "...",
"metrics": {
"accuracy": 0.XX
},
"config": {...},
"logs": "..."
}
推荐工具：
● Hydra / OmegaConf
● MLflow / W&B

3.6 Evaluation Agent
功能：
● 分析实验结果
● 判断是否优于 baseline
● 提取规律
输出：
{
"insight": "...",
"improvement": true/false,
"next_action": "..."
}

3.7 Iteration Agent
功能：
● 基于结果优化 idea
策略：
● 模型结构修改
● loss 调整
● 数据增强

3.8 Writing Agent
功能：
● 自动生成论文（LaTeX）
● 生成图表（matplotlib）
● 生成表格
输出结构：
● abstract
● introduction
● related work
● method
● experiment
● conclusion

4. Memory 系统设计
4.1 Paper Memory
● 类型：向量数据库
● 内容：论文 embedding + metadata
技术：
● FAISS / Weaviate

4.2 Experiment Memory
● 存储：
  ○ config
  ○ metrics
  ○ logs

4.3 Idea Memory
● 每次 idea 的演化记录

5. Agent Loop（闭环）
核心循环：
while not converged:
idea = generate()
code = implement()
result = experiment()
insight = analyze()
idea = refine()

7. MVP 实现方案（强烈建议）
Phase 1（最关键）
实现：

● Evaluation Agent
形成最小闭环：
Idea → Code → Run → Analyze

Phase 2

增加：
● Writing Agent（论文生成）

9. 扩展功能（高级）
9.1 Reviewer Simulator
● 自动生成审稿意见
9.2 SOTA Tracker
● 自动更新最新论文
9.3 Failure Analysis
● 分析失败实验原因

10. 风险与限制
可实现：
● 自动 baseline
● 自动调参
● 自动论文初稿
难点：
● 真正创新 idea
● 顶会级 novelty

11. 未来方向
● Self-improving agent
● Multi-agent debate（idea 竞争）
● 自动 benchmark 构建

12. 总结
该系统本质是：
一个“科研自动化闭环系统”，通过多 Agent 协作，实现：
Idea → Experiment → Insight → Paper
核心成功关键在于：
1. 实验自动化（Experiment Agent）
2. 反馈闭环（Iteration）
3. 高质量 memory（RAG + logs）
建议优先实现 MVP，再逐步扩展。
