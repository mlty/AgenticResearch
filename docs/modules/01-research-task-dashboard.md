# Research Task Dashboard 模块文档

## 1. 模块定位

Research Task Dashboard 是用户进入产品后的任务总览页，用于创建研究任务、查看任务状态、进入具体任务工作区。它是整个科研闭环的入口。

## 2. 用户价值

1. 快速了解当前有哪些研究任务在运行。
2. 判断每个任务处于 idea、实验、分析还是写作阶段。
3. 进入需要人工干预的任务。

## 3. 用户故事

```text
作为研究者，我希望在一个页面看到所有研究任务的进展，以便快速决定今天应该处理哪个任务。
```

## 4. MVP 功能范围

### 4.1 必须做

- [ ] 创建 research task。
- [ ] 展示任务列表。
- [ ] 展示任务状态：draft、running、blocked、completed、failed。
- [ ] 展示当前活跃节点和最近一次实验结果。
- [ ] 支持进入任务详情页。

### 4.2 暂不做

- [ ] 团队协作看板。
- [ ] 多项目权限管理。
- [ ] 复杂筛选和报表。

## 5. 页面与交互

页面包含：

1. 顶部创建任务入口。
2. 任务状态分组。
3. 任务卡片或任务表格。
4. 需要用户干预的任务提醒。

核心操作：

1. 新建任务。
2. 打开任务。
3. 暂停或归档任务。
4. 查看最近运行结果。

## 6. 数据对象

| 对象 | 用途 |
| --- | --- |
| ResearchTask | 任务基础信息 |
| TaskNode | 当前节点状态 |
| Experiment | 最近实验结果 |
| Intervention | 待处理人工干预 |

## 7. API / 事件

| 类型 | 名称 | 说明 |
| --- | --- | --- |
| API | `POST /api/tasks` | 创建任务 |
| API | `GET /api/tasks` | 获取任务列表 |
| API | `GET /api/tasks/{task_id}` | 获取任务详情 |
| Event | `task.created` | 任务创建成功 |
| Event | `task.status_changed` | 任务状态变化 |

## 8. 状态与异常

| 状态 | 处理方式 |
| --- | --- |
| Empty | 显示创建首个研究任务入口 |
| Loading | 展示骨架屏 |
| Failed | 显示重试入口和错误摘要 |
| Blocked | 高亮需要用户处理的节点 |

## 9. 验收标准

- [ ] 用户可以在 1 分钟内创建一个任务。
- [ ] 用户能从列表进入任务详情。
- [ ] 任务状态变化能在页面上实时或准实时更新。
- [ ] 被阻塞任务能明确提示阻塞原因。
